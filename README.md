# Sauce Demo Shopify - QA Testing Project

## Project Overview

This project demonstrates a manual software testing process performed on the Sauce Demo Shopify e-commerce application.

The goal of the project is to verify the main functional areas of the application, identify potential defects, and document the testing process and results.

## Application Under Test

**Application:** Sauce Demo Shopify

**URL:** https://sauce-demo.myshopify.com/

**Testing Type:** Manual Functional Testing

---

## Testing Scope

The following functionalities were included in the testing scope:

- Customer Login
- Customer Account Creation
- Product Display
- Product Details
- Product Availability
- Product Pricing
- Shopping Cart
- Checkout
- Order Summary
- Order Completion
- Order Confirmation

---

## Testing Process

The testing process followed these main steps:

1. Reviewed the application requirements.
2. Designed test cases based on the defined requirements.
3. Executed the test cases manually.
4. Recorded the actual results.
5. Compared actual results with expected results.
6. Documented the test execution results.
7. Prepared the final test summary.
