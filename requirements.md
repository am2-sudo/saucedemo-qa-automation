# Software Requirements

## Scope

This project focuses on testing the critical user flows of the SauceDemo
e-commerce web application through manual testing and automated testing.

## Functional Requirements

### Authentication

- REQ-001: The system shall allow users to log in using valid credentials.
- REQ-002: The system shall display an error message when invalid credentials are provided.
- REQ-003: The system shall prevent locked users from accessing the application.

### Products

- REQ-004: The system shall display the available products.
- REQ-005: The user shall be able to view product details.
- REQ-006: The user shall be able to sort products using the available sorting options.

### Shopping Cart

- REQ-007: The user shall be able to add a product to the shopping cart.
- REQ-008: The user shall be able to remove a product from the shopping cart.
- REQ-009: The system shall display the correct number of items in the shopping cart.

### Checkout

- REQ-010: The user shall be able to proceed to checkout.
- REQ-011: The system shall validate required checkout information.
- REQ-012: The user shall be able to review the order before completing it.

### Order Completion

- REQ-013: The user shall be able to complete a valid order.
- REQ-014: The system shall display an order confirmation after successful checkout.
